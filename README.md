# SalesInsight PY

Mini-Projeto Avaliativo do Módulo 01 — Desenvolvimento de IA para Análise Preditiva.

## Estrutura do Projeto

```text
data/raw/          → dataset bruto e imutável
notebooks/         → exploração e desenvolvimento analítico
src/sales_insight/ → código Python reutilizável
reports/           → resultados exportados
reports/figures/   → gráficos exportados
salesinsight.py    → futuro ponto de entrada executável
```
